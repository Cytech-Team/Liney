Questions

คำถามที่พบบ่อย

Liney เป็นแอป Official ของ LINE หรือไม่?

ไม่ใช่ Liney เป็นโปรเจกต์อิสระ ไม่ได้สังกัด ได้รับอนุญาต หรือรับรองโดย LY Corporation และไม่ได้ใช้ official branding หรือ SDK ในฐานะผลิตภัณฑ์ของ LINE

ทำไมต้องอ่านประกาศก่อน Login?

เพราะการใช้ implementation ที่ไม่เป็นทางการอาจไม่สอดคล้องหรืออาจขัดกับ TOS ของ LINE และมีความเสี่ยงต่อบัญชี ผู้ใช้ต้องตัดสินใจด้วยตนเองก่อนดำเนินการต่อ

Liney เก็บรหัสผ่านหรือส่งผ่านเซิร์ฟเวอร์ของ Liney ไหม?

Liney Desktop ส่ง credential จากเครื่องผู้ใช้ไปตาม flow ของ LINEJS และไม่ตั้งใจเก็บ password ถาวร ส่วน Liney Web Public ใช้ QR Code เท่านั้นและประมวลผล session ผ่าน Public Home Runner แยกต่อ browser โดยไม่เปิด email/password login บนเว็บ

Logout ลบประวัติข้อความด้วยหรือไม่?

ไม่ การ logout ล้าง session และ credential ส่วนประวัติในเครื่องต้องล้างผ่านคำสั่งล้างประวัติแยกต่างหาก การล้าง local history ไม่ได้ลบข้อความบน LINE

มี video call หรือ group call แล้วหรือยัง?

ยังไม่โฆษณาเป็นฟีเจอร์พร้อมใช้ ขอบเขตเสียง 1:1 จะเปิดเมื่อผ่าน live validation จริงบนระบบเป้าหมาย ส่วน video, group call และ LiveTalk ยังไม่เปิดใช้งาน

แจ้งปัญหาอย่างไรให้ปลอดภัย?

ส่งรายละเอียดที่ทำซ้ำได้, เวอร์ชัน, ดิสโทร และ log ที่ redacted เท่านั้น ห้ามแนบ password, QR, PIN, token, session file, auth.json หรือ linejs-session.json

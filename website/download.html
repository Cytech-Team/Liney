02 / INSTALL GUIDE

เอาคำสั่งไปเลย

TerminalAppImage
cd ~/Downloads

ดาวน์โหลดไฟล์จากด้านบน แล้วเปิด Terminal ในโฟลเดอร์ที่เก็บไฟล์

ติดตั้งเสร็จแล้วทำอะไรต่อ?

เปิด Liney → อ่านคำเตือน → เข้าสู่ระบบผ่าน QR หรือ Email ตามโหมดที่รองรับ ก่อนรายงานปัญหาโปรดลบข้อมูลบัญชีและ token ออกจาก log

03 / COMPATIBILITY

สิ่งที่ควรรู้ก่อน
กดติดตั้ง

ความสามารถบางส่วนขึ้นอยู่กับเวอร์ชันและสภาพแวดล้อมของระบบ Linux ที่ใช้งาน

01

Linux Only

ปัจจุบันยังไม่มีเวอร์ชัน Windows หรือ macOS ที่รองรับ เน้น Linux x86_64 / aarch64 ตามไฟล์ที่เผยแพร่จริง

02

WebKitGTK

ส่วน UI ใช้ Tauri กับ WebKitGTK 4.1 และ GTK3 บน Linux

03

Native capabilities

การโทรและแชร์หน้าจอใช้ Native helper แยกความสามารถของไมค์ กล้อง และ Wayland/X11 การรองรับขึ้นกับอุปกรณ์

04

Local credentials

ใช้ Secret Service หรือ KWallet สำหรับ credential หากใช้ไม่ได้จะเป็น session-only เพื่อเลี่ยง plaintext token

04 / QUESTIONS

คำถามที่
คนมักสงสัย

ดูรายละเอียดเพิ่มเติมในเอกสารและส่งปัญหาที่ทำซ้ำได้ผ่าน GitHub Issues

แจ้งปัญหา ↗
Liney เป็นแอป LINE ทางการไหม?

ไม่ใช่ Liney เป็นไคลเอนต์อิสระ ใช้การเชื่อมต่อที่ไม่เป็นทางการและไม่ได้รับรองโดย LY Corporation การใช้งานอาจมีความเสี่ยงต่อบัญชี อ่าน Safety Notice

ทำไมยังใช้ yay -S liney ไม่ได้?

ในโปรเจกต์มีไฟล์ PKGBUILD แต่ยังไม่ปรากฏว่าเผยแพร่แพ็กเกจบน AUR จริง ใช้ AppImage หรือไฟล์จาก GitHub Releases ก่อน

โทรเสียงและวิดีโอคอลเสถียรหรือยัง?

มีโครงสร้างการโทรเสียง 1:1 แล้ว แต่การรับสายและวิดีโอคอลยังอยู่ในระดับทดลอง ต้องทดสอบด้วยบัญชีจริงเพิ่มเติม

Liney Lite หรือ Windows/macOS จะมาเมื่อไร?

ยังไม่มีกำหนด Liney Lite เป็นเพียงแนวคิดที่พิจารณาอยู่ ส่วนแพลตฟอร์มอื่นยังไม่ใช่เป้าหมายปัจจุบัน

ข้อมูล Liney อยู่ที่ไหน?

Liney Desktop เก็บข้อมูลใน ~/.local/share/liney/ โดยใช้ SQLite ภายในเครื่อง สำหรับรายละเอียดการจัดการข้อมูลดู Privacy Notice

Liney Web เหมือนแอป Desktop ไหม?

ไม่เหมือนกันทั้งหมด Liney Web เป็นโหมดแยกที่มีรูปแบบการทำงานและข้อจำกัดต่างจากการใช้งานบนเครื่อง ดู Web App สำหรับรายละเอียด

ข้อควรรู้

Liney ไม่ได้สังกัดหรือได้รับการรับรองจาก LY Corporation การใช้โปรโตคอลไม่เป็นทางการอาจขัดกับข้อกำหนดของ LINE และอาจกระทบต่อบัญชีผู้ใช้

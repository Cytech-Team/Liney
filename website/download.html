Install guide

ติดตั้งและเปิดใช้งาน

ตัวอย่างคำสั่งสำหรับไฟล์ที่ดาวน์โหลดแล้ว ให้เปิด Terminal ในโฟลเดอร์ที่เก็บไฟล์ก่อน

เลือกวิธีติดตั้ง

Terminal · AppImage
chmod +x Liney-*-linux-x86_64.AppImage
./Liney-*-linux-x86_64.AppImage

ดาวน์โหลด AppImage จากด้านบนแล้วเปิด Terminal ในโฟลเดอร์ดาวน์โหลด

Compatibility

ข้อกำหนดและข้อจำกัด

Liney ยังอยู่ระหว่างพัฒนา ระบบบางส่วนขึ้นอยู่กับความสามารถของ Linux Desktop และโปรโตคอล LINEJS

Linux Desktop

แอปใช้ WebKitGTK 4.1 และ GTK3 บน Linux; รองรับการทำงานร่วมกับ Wayland / X11 ตามความสามารถของระบบ

Audio / Capture

ฟังก์ชันเสียงและแชร์หน้าจอใช้ Native helper ของ Liney ไม่จำเป็นต้องติดตั้ง FFmpeg, GStreamer หรือ PipeWire command-line tools ทุกกรณี

Credential wallet

ใช้ Secret Service / KWallet หากมี ถ้าไม่พร้อมจะใช้ session-only แทนการบันทึก credential แบบ plaintext

Supported platforms

เผยแพร่สำหรับ Linux x86_64 และ aarch64 ตามไฟล์ใน Release เท่านั้น Windows และ macOS ยังไม่มีรุ่นที่รองรับ

FAQ

คำถามที่พบบ่อย

หากมีปัญหา โปรดส่งเวอร์ชัน ดิสโทร และ log ที่ลบข้อมูลส่วนตัวแล้วผ่าน GitHub Issues

เปิด Issues ↗
Liney เป็นแอปของ LINE อย่างเป็นทางการหรือไม่?

ไม่ใช่ Liney พัฒนาอย่างอิสระและไม่ได้รับการรับรองจาก LY Corporation การใช้โปรโตคอลไม่เป็นทางการอาจขัดกับข้อกำหนดบริการและมีความเสี่ยงต่อบัญชี อ่าน Safety Notice

ทำไมยังติดตั้งผ่าน yay / paru ไม่ได้?

ณ วันที่ตรวจสอบ ยังไม่พบแพ็กเกจ liney บน AUR แม้ Repository มี PKGBUILD แล้ว ให้ใช้ไฟล์ AppImage หรือรูปแบบอื่นที่มีใน GitHub Releases ก่อน

Liney Lite หรือ Windows / macOS มีให้ดาวน์โหลดไหม?

ยังไม่มี Liney Lite เป็นเพียงแนวคิดที่อยู่ระหว่างพิจารณา ปัจจุบันโครงการเน้นการพัฒนาและปรับปรุงรุ่น Linux

โทรเสียงและวิดีโอคอลใช้ได้ครบหรือยัง?

มีส่วนการโทร 1:1 ในโค้ด แต่ความเสถียรต้องผ่านการทดสอบกับบัญชีจริงต่อ การรับสายและวิดีโอคอลยังเป็นฟีเจอร์ทดลอง ไม่รับประกันว่าใช้ได้ทุกกรณี

Liney เก็บข้อมูลไว้ที่ไหน?

แอป Desktop ใช้โฟลเดอร์ ~/.local/share/liney/ เพื่อเก็บข้อมูลและประวัติข้อความใน SQLite โดยไม่มี message relay ส่วนกลางของ Liney สำหรับแอป Desktop

Liney Web กับ Desktop เหมือนกันไหม?

Liney Web เป็นช่องทางทดลองแยกต่างหากและมีข้อจำกัดต่างจาก Desktop ไม่ควรมองว่าทุกความสามารถบน Desktop ใช้ได้บนเว็บด้วย ดู Liney Web

Safety Notice

ประกาศนี้เป็นส่วนหนึ่งของการใช้งาน Liney ทุกคนควรอ่านและประเมินความเสี่ยงก่อนเข้าสู่ระบบ

ในหน้านี้
สถานะของ Lineyความเสี่ยงบัญชีการใช้งานอย่างปลอดภัยเมื่อเกิดปัญหา

คำเตือนสำคัญ

Liney ไม่ใช่แอป Official ของ LINE และไม่ได้รับการรับรองจาก LY Corporation การใช้ LINEJS อาจไม่สอดคล้องหรืออาจขัดกับ Terms of Service (TOS) ของ LINE บัญชีอาจถูกจำกัด ระงับ หรือใช้งานไม่ได้ ใช้งานด้วยความระมัดระวังและความเสี่ยงของคุณเอง

อัปเดตเอกสาร: 2026-09-05

1. สถานะของซอฟต์แวร์

Liney เป็น native Linux desktop client ที่พัฒนาโดย Cytech Team Development เป็นโปรเจกต์อิสระ ไม่ได้เป็นตัวแทน ไม่ได้สังกัด และไม่ได้แสดงตัวว่าเป็นผลิตภัณฑ์ของ LINE หรือ LY Corporation

Liney ใช้ LINEJS เป็นชั้น protocol และบริการของ LINE อาจเปลี่ยนแปลงได้ตลอดเวลา ฟังก์ชันอาจหยุดทำงาน ถูกจำกัด หรือมีพฤติกรรมแตกต่างจาก official client โดยไม่มีการรับประกันล่วงหน้า

2. ความเสี่ยงต่อบัญชีและข้อมูล

  • การใช้ client หรือ protocol ที่ไม่เป็นทางการอาจขัดกับ TOS, policy หรือข้อกำหนดอื่นของ LINE
  • LINE อาจตรวจพบการใช้งานและจำกัด ระงับ หรือยุติบัญชีได้ Liney ไม่รับประกันว่าบัญชีจะปลอดจากการดำเนินการดังกล่าว
  • อย่าใช้บัญชีที่คุณไม่สามารถยอมรับการสูญเสียการเข้าถึงได้ โดยเฉพาะบัญชีงาน บัญชีธุรกิจ หรือบัญชีที่มีข้อมูลสำคัญเพียงชุดเดียว
  • QR, PIN, password, session และ token เป็นข้อมูลลับ ห้ามส่งให้ผู้พัฒนา หรือโพสต์ใน issue, screenshot, log และแชตสาธารณะ

3. แนวทางการใช้งานอย่างปลอดภัย

  • ใช้เฉพาะบัญชีและห้องสนทนาที่คุณมีสิทธิ์ใช้งาน
  • ตรวจสอบ source และ checksum ของ release ก่อนติดตั้ง
  • ใช้ password login เฉพาะเมื่อเข้าใจว่า credential ถูกใช้กับ flow ของ LINEJS จากเครื่องของคุณ
  • เปิด persistent session เฉพาะบนเครื่องที่คุณควบคุมและมี user account ที่ปลอดภัย
  • อัปเดตจาก release ที่ตรวจสอบได้ และหยุดใช้ทันทีหากเห็นพฤติกรรมผิดปกติ
  • ใช้แชตตามปกติอย่างรับผิดชอบ ไม่ทำ spam หรือส่งข้อความจำนวนมากแบบอัตโนมัติ

4. การใช้งานที่โครงการไม่สนับสนุน

ห้ามใช้ Liney เพื่อ spam, mass messaging, account farming, credential harvesting, bypass security controls, รบกวนบริการ LINE, หลอกลวงผู้ใช้, ส่ง malware หรือทำสิ่งที่ผิดกฎหมายและผิดสิทธิ์ของผู้อื่น

5. เมื่อเกิดปัญหา

หาก login ไม่ได้, บัญชีมีความผิดปกติ, หรือพบพฤติกรรมที่อาจกระทบความปลอดภัย ให้หยุดใช้ Liney และตรวจสอบผ่านช่องทาง official ของ LINE ก่อน อย่าพยายามแก้ด้วยการส่ง credential หรือ session ให้บุคคลอื่น

การรายงานปัญหาควรใส่เฉพาะเวอร์ชัน, ดิสโทร, ขั้นตอนทำซ้ำ และ log ที่ลบข้อมูลลับแล้ว ติดต่อได้ที่ namnarak@namnarak.in.th

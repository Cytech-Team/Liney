Privacy Notice

อธิบายว่า Liney จัดการ credential, ข้อความ, media cache และข้อมูลการใช้งานอย่างไร

ในหน้านี้
สรุปสั้น ๆข้อมูลที่เกี่ยวข้องการเก็บรักษาการควบคุมของผู้ใช้ติดต่อ

วันที่มีผล: 2026-09-05

สรุปในประโยคเดียว

Liney Desktop ประมวลผล LINEJS บนเครื่องผู้ใช้ ส่วน Cloudflare Pages ใช้เผยแพร่เว็บไซต์ข้อมูลผลิตภัณฑ์และไฟล์ดาวน์โหลดเท่านั้น

1. ขอบเขตของประกาศนี้

ประกาศนี้ครอบคลุมแอป Liney, engine และเว็บไซต์เอกสารแบบ static นี้ โดยอธิบายการจัดการข้อมูลที่ Liney ควบคุมได้ ไม่ใช่ประกาศความเป็นส่วนตัวของ LINE, LY Corporation, GitHub, Secret Service, KWallet หรือบริการภายนอกอื่น

เมื่อคุณใช้บริการ LINE ผ่าน Liney การเก็บ ใช้ และส่งข้อมูลโดย LINE อยู่ภายใต้นโยบายและข้อกำหนดของ LINE เอง โปรดอ่านเอกสารของบริการนั้นด้วย

2. ข้อมูลที่ Liney เกี่ยวข้อง

ข้อมูลอยู่ที่ไหน / ใช้ทำอะไรพฤติกรรมสำคัญ
Refresh credentialSecret Service หรือ KWallet เมื่อ wallet ใช้ได้ เพื่อ restore sessionไม่ตั้งใจเก็บลง plaintext session file หรือ log
Passwordใช้ชั่วคราวใน flow email/password จาก UI ไปยัง local engineLiney ล้างจาก UI ทันที และไม่เก็บใน localStorage, session file หรือ wallet
Session / sync stateไฟล์ private หรือ SQLite ใน data directory ของผู้ใช้สร้างด้วยสิทธิ์จำกัดและเขียนแบบ atomic เมื่อทำได้
ข้อความและ metadataSQLite ในเครื่อง เพื่อแสดง history, unread และ sync stateเก็บจนกว่าผู้ใช้จะสั่งล้าง local history
Preview mediaLRU disk cache แยกจาก databaseไฟล์ต้นฉบับไม่เก็บถาวรเว้นแต่ผู้ใช้สั่งบันทึก
Diagnostic logsเครื่องของผู้ใช้ตามการตั้งค่าระบบควร redact ก่อนแชร์ และ Liney ไม่ควรใส่ token/password ลง log

3. การส่งข้อมูลไปยังบริการอื่น

สำหรับ Liney Desktop ข้อมูลที่จำเป็นต่อการ login, sync, ส่งข้อความ หรือ media จะเดินทางระหว่างเครื่องของคุณกับบริการ LINE ตามการทำงานของ LINEJS

ถ้าคุณเลือกเปิดไฟล์, notification, audio route หรือการเชื่อมต่อภายนอก ระบบปฏิบัติการและบริการที่คุณเลือกอาจประมวลผลข้อมูลเพิ่มตามสิทธิ์และการตั้งค่าของระบบนั้น

5. การเก็บรักษาและการลบ

  • Logout: Desktop ล้าง session/credential ตามวิธีที่ Engine รองรับ; ผู้ใช้ลบข้อมูล local ที่เหลือจาก data directory ของตนเองได้
  • Clear history: ลบข้อความ, outbox และ media cache ในเครื่องตามคำสั่งของผู้ใช้ แต่ไม่ลบข้อความบน LINE
  • Wallet unavailable: ใช้ session-only และไม่เขียน refresh credential ลงไฟล์ plaintext
  • ถอนการติดตั้ง: อาจไม่ลบ data directory โดยอัตโนมัติ ผู้ใช้ควรตรวจและลบข้อมูลในเครื่องตามความต้องการ

6. การควบคุมของผู้ใช้

คุณควรควบคุมเครื่อง, user account, data directory และ wallet ของตนเอง ใช้ logout, clear history และถอนการติดตั้งเมื่อไม่ต้องการให้ข้อมูลอยู่ในเครื่องอีกต่อไป สำรองข้อมูลเฉพาะที่จำเป็นและเก็บ backup อย่างปลอดภัย

อย่าแชร์ไฟล์ auth.json, linejs-session.json, database, token, QR หรือ PIN ใน issue, screenshot, archive หรือช่องทางสาธารณะ

7. การวิเคราะห์การใช้งาน

เว็บไซต์เอกสารนี้ไม่มีโฆษณา ไม่มีระบบ analytics ของ Liney และไม่มี telemetry ที่โครงการตั้งใจส่งไปยัง central backend โดยค่าเริ่มต้น หาก release ใดมีการเพิ่มบริการวัดผลหรือ third-party integration จะต้องอธิบายไว้ในเอกสารและการตั้งค่าที่เกี่ยวข้องก่อน

8. การเปลี่ยนแปลงและการติดต่อ

ประกาศนี้อาจเปลี่ยนเมื่อสถาปัตยกรรมหรือฟังก์ชันของ Liney เปลี่ยน วันที่มีผลจะแสดงไว้ด้านบน สำหรับคำถามเรื่อง privacy ติดต่อ namnarak@namnarak.in.th และอย่าส่ง credential หรือข้อมูลแชตจริงมาด้วย

LINEY / DEVICE COMPATIBILITY

เครื่องนี้ใช้ Liney
ได้จริงไหม?

ตรวจความพร้อมแบบใช้เครื่องของคุณเอง ไม่ต้องติดตั้งส่วนขยาย และไม่ส่งข้อมูลระบบของคุณไปให้ผู้พัฒนา

การทดสอบ Local Engine อาจแสดงคำขอสิทธิ์เข้าถึงเครือข่ายภายในจาก Chrome ต้องกดยอมรับด้วยตัวเองถ้าต้องการใช้งาน

WHAT'S NEXT?

ทำอะไรต่อ
ตามผลตรวจ

Liney Web ใช้ UI จาก Cloudflare Pages แต่โปรโตคอล LINE และข้อมูลบัญชียังต้องรันในเครื่องผู้ใช้

01 / LOCAL ENGINE

เปิด Engine บนเครื่องนี้

เครื่องที่อนุญาตให้รันโปรแกรม Linux สามารถใช้ Local LINEJS Engine ผ่าน 127.0.0.1 โดยตรง ไม่ต้องติดตั้ง Chrome Extension

ดูการติดตั้ง Engine ↗
02 / CHROMEBOOK

เครื่องที่มี Admin

หน้าเว็บไม่สามารถอ่านหรือข้ามนโยบาย Google Workspace Admin ได้ทั้งหมด ถ้า Linux environment ถูกปิด ให้ขอสิทธิ์จาก Admin ก่อน

ข้อมูลนโยบาย ChromeOS ↗
03 / BETA INVITATION

โค้ดเชิญเข้าร่วมทดสอบ

สามารถเพิ่มโค้ดเชิญแบบจำกัดสิทธิ์ได้ในอนาคต แต่ตอนนี้ยังไม่มีระบบออกโค้ดจริง และไม่ควรอ้างว่ามีการยืนยันสิทธิ์แล้ว

Liney Web / Local Bridge

เว็บแอป Liney ที่ไม่ย้าย credential ออกจากเครื่อง

หน้านี้เป็น entrypoint สำหรับโหมดเว็บของ Liney: หน้าเว็บทำหน้าที่เป็น UI ส่วน engine, credential, E2EE key และ media cache ยังอยู่ในเครื่องผู้ใช้ผ่าน Local Bridge

ติดตั้ง Desktop ก่อน อ่านข้อควรรู้

ตอนนี้

Desktop native

โหมดหลักยังเป็นแอป Linux/Tauri ที่คุยกับ LINE โดยตรงจากเครื่องคุณ เหมาะกับการใช้งานจริงที่สุด

  • credential เก็บใน Secret Service/KWallet หรือ session-only
  • SQLite, media cache และ E2EE storage อยู่ในเครื่อง
  • ไม่มี Liney relay server กลางสำหรับข้อความ

กำลังเตรียม

Liney-Website

เว็บ UI จะเชื่อมกับ Local Bridge บนเครื่องเดียวกัน เพื่อให้เปิดใช้งานผ่านเบราว์เซอร์ได้โดยไม่ส่ง token ไป Cloudflare หรือ server ของ Liney

Client label Liney-Website

Security model

โหมดเว็บต้องผ่าน Local Bridge เท่านั้น

การให้เว็บไซต์ Cloudflare ถือ credential โดยตรงไม่ปลอดภัยและไม่ตรงกับแนว local-first ของ Liney ดังนั้นเว็บแอปจริงจะเป็น browser UI ที่คุยกับ engine ในเครื่อง

01

Website

เสิร์ฟเฉพาะ UI/static asset และตั้ง label เป็น Liney-Website

02

Local Bridge

รับคำสั่งจาก localhost เท่านั้น พร้อม allowlist origin และ session pairing

03

LINE engine

ทำงานในเครื่องเดิม ใช้ SQLite, keyring และ media cache ชุดเดียวกับแอป Desktop

Liney Web App / Chromebook mode

ใช้ Liney ผ่านเว็บได้ โดยไม่ทำฐานข้อมูลแชตกลาง

เป้าหมายของโหมดเว็บคือให้คนที่ติดตั้งแอปไม่ได้ เช่น Chromebook โรงเรียน ใช้ Liney จากเบราว์เซอร์ได้ โดยรหัสผ่านไม่ถูกจำบน server และไม่มีฐานข้อมูลข้อความของผู้ใช้ให้แอดมินเปิดอ่าน

ดูโมเดลความปลอดภัย อ่าน Privacy ของ Web App

สำหรับผู้ใช้

เปิดในเว็บเดียว

โหมดนี้จะเป็น PWA/เว็บแอปที่เข้าได้จาก liney.namnarak.in.th/app ไม่ต้องติดตั้ง package นอกเครื่อง เหมาะกับเครื่องที่ถูกล็อกนโยบายการติดตั้ง

  • Client label แยกชัด เช่น Liney-Website หรือ Liney-Chromebook
  • cache อยู่ใน browser ของผู้ใช้
  • มีปุ่มล้างข้อมูลเว็บในเครื่อง

สำหรับ privacy

No central inbox

Liney Web จะไม่สร้างฐานข้อมูลแชตกลางของโครงการ และจะไม่เก็บ LINE password ไว้ใน Cloudflare, GitHub หรือ server ของ Liney

Server-side storage ไม่มี message DB โดยค่าเริ่มต้น

Runtime model

ต้องมี Web Runtime ไม่ใช่ static page อย่างเดียว

เว็บ static อย่างเดียวคุยกับ LINE Desktop API ได้ไม่ครบเพราะติด CORS, header, long-polling และ session flow ดังนั้น Chromebook mode ต้องมี browser vault + relay ที่ไม่เก็บข้อมูลถาวร

01

Browser vault

เก็บ session/cache ใน IndexedDB และเข้ารหัสด้วย WebCrypto ฝั่ง browser รหัสผ่านไม่ลง localStorage

02

Stateless relay

Cloudflare Worker ส่งต่อเฉพาะ request ที่จำเป็นไป LINE แบบชั่วคราว ไม่มี KV/D1/R2 เก็บข้อความหรือ token

03

LINE engine

ระบบประมวลผล protocol เพื่อให้แอปทำงานได้ แต่ต้อง redact log และห้ามทำ inbox database กลาง

พูดให้ตรง:

เราจะไม่เขียนว่า server “ไม่มีทางเห็นข้อมูลใด ๆ” ถ้า request วิ่งผ่าน relay เพราะระบบต้องประมวลผลชั่วคราวเพื่อให้ใช้งานได้ แต่จะเขียนว่าไม่มีการเก็บ password/message database ถาวร ไม่มี UI ให้คนมาเปิดอ่าน และ log ต้องไม่เก็บ token หรือ body ของแชต

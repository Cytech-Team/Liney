02 / HOW IT WORKS

แอปจริง
ไม่ใช่แค่ แท็บเว็บ

UI ใช้ React และ Tauri ส่วน LINEJS ทำงานใน Bun/TypeScript sidecar พร้อม SQLite สำหรับเก็บข้อมูลในเครื่อง นี่คือโครงสร้างของ Liney Desktop — ไม่ใช่ LINE Official และไม่ใช่ระบบ relay ข้อความกลาง

TECH STACK

แต่ละส่วน
มีหน้าที่ของมัน

นี่คือภาพรวมจากซอร์สของ Desktop การทำงานจริงขึ้นกับเวอร์ชันของ LINEJS และระบบ Linux ที่ติดตั้ง

01 / FRONTEND

React + Tauri

หน้าตาและการโต้ตอบใช้เว็บเทคโนโลยี โดยฝังอยู่ใน WebView ของระบบ แทนการแบก Chromium แบบ Electron

02 / ENGINE

Bun + LINEJS

Engine ทำหน้าที่เชื่อมต่อและประมวลผลข้อความผ่าน LINEJS พร้อมระบบจัดการงานเบื้องหลัง

03 / DATA

SQLite + Outbox

ฐานข้อมูลและคิวข้อความอยู่ในเครื่องของผู้ใช้ ไม่ได้หมายความว่าข้อมูลที่ LINE ให้บริการจะเก็บในเครื่องทั้งหมด

04 / DESKTOP

Native helpers

ระบบเสียง การแจ้งเตือน และการจับภาพหน้าจอทำงานร่วมกับ Native API และ Wayland/X11 ตามสภาพแวดล้อม

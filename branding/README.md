# Liney branding

`liney-logo.jpg` is the project artwork supplied for Liney branding and
documentation. It is not the official LINE logo or official LINE artwork.

`packaging/liney.png` is a 512px RGBA icon derived directly from the supplied
artwork. The outside corners are transparent and the rounded artwork fills the
desktop icon bounds; it is used as the Linux desktop icon, launcher icon, and
Tauri icon source. `public/liney-logo.png` is the matching web/UI copy. The
compact vector mark in [`packaging/liney.svg`](../packaging/liney.svg) remains
available for surfaces where a small SVG-only mark is preferable.

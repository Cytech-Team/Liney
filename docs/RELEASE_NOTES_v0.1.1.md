# Liney 0.1.1 — Linux Release

This release bundles the latest Linux desktop experience from October 2026.

- Refreshed desktop interface, contact/friend sync diagnostics and chat history recovery.
- Expanded LineJS integrations, groups, Notes, albums, profile management, and raw Flex inspection (developer setting).
- E2EE persistence/recovery updates and incremental background sync.
- Experimental audio/video calling, screen capture helpers for Wayland and X11.
- Linux packaging for .deb, .rpm, AppImage, Portable, Flatpak and AUR manifests.

**Status:** Stable GitHub Release distribution (not an official LINE/LY Corporation client). LINE protocol functionality may change without notice. Some functions (including calls, screen sharing, VOOM/Notes) are experimental or require compatible accounts/environments. Supported packages do not imply that every feature is available on every desktop.

Binary distributions are built and verified by the GitHub Actions release workflow. Checksum files accompany Linux artifacts. Flatpak on Flathub and AUR publication are separate from GitHub Releases and require their own distribution review/account access.
